## Not covered / needs human judgment
- The rate-limit alert in a browser and a real text on a handset. Both need a real SMS provider, so TC-3.1 holds them.

- Accessibility beyond the code input attributes: screen-reader reading of the alerts and focus order across the steps. No automated audit ran.
- Performance: not in scope. The new queries read indexed columns for one phone.
- Compatibility: Chromium only. Safari autofill of `one-time-code` needs an iPhone.
- Migration on Postgres: the build checked `db:generate` on a Postgres playground; this run used D1 only.
