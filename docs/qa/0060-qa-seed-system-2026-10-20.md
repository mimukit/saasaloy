- The completeness test read a stale Vitest glob cache, so it missed a new table or a new slice.
- The Postgres test setup accepted any `<prefix>_<x>` database and force-dropped it on a failed migration.
- `db:seed` checked only the database name, not the server.
- The seeded expired API key was deleted on the first list call, and the seeded rollout flag was not registered, so no page showed it.
- An upsert on a slice key could rewrite a text primary key.
- The admin API keys page failed with `keys.data?.map is not a function`, and a later `add` run dropped `admin` from `PUBLIC_API_URL`. `main` has both bugs.
